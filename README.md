---

## 📌 Problem Statement

Write a C++ program demonstrating the use of a **class, constructor, destructor, and user-defined functions**.

The program creates a `Student` object, initializes its data using a parameterized constructor, displays student information using a user-defined member function, and demonstrates the automatic execution of a destructor when the object is destroyed.

---

## 🎯 Objectives

1. Understand the concept of classes and objects in C++.
2. Implement constructors and destructors.
3. Create and use user-defined member functions.
4. Understand the lifecycle of an object in C++.
