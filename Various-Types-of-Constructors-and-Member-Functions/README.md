# Various Types of Constructors and Member Functions

This C++ program demonstrates different types of constructors and member functions using a `Student` class.

## Concepts Demonstrated

- Default constructor
- Parameterized constructor
- Copy constructor
- Member function to display student details
- Member function to update marks
- Private data members and encapsulation

## Program Flow

1. Creates a `Student` object using the default constructor.
2. Creates another `Student` object using the parameterized constructor.
3. Updates the second student's marks using `updateMarks()`.
4. Creates a third object by copying the second object.
5. Displays the details of each object.

## Build and Run

From this folder, compile the program with:

```bash
g++ main.cpp -o main
```

Run it with:

```bash
./main
```

On Windows PowerShell, use:

```powershell
./main.exe
```
